## 4. 高频问题与回答要点

### 为什么不能把所有 Lab 合并到一个分支？

MIT 为每个实验提供不同基线和评分器，部分修改相互替代。独立分支能保持官方验收
环境、清晰差异和可复现历史；`course-project` 负责统一导航和自动化。

### lazy allocation 与 COW 的 page fault 有什么区别？

lazy fault 对应“虚拟区合法但尚无物理页”，处理方式是分配零页；COW fault 对应“已有
只读共享物理页上的写操作”，处理方式是复制或恢复独占页写权限。两者都必须先验证
fault 地址，失败时杀死进程。

### COW 为什么需要引用计数？

父子页表可能同时指向一个物理页。只有最后一个映射消失时才能释放该页，否则会造成
use-after-free；永不释放则会泄漏。引用计数把物理页生命周期与共享映射数绑定。

### 每 CPU allocator 如何防止线程迁移？

读取 `cpuid()` 并操作对应链表期间关闭中断，保证当前执行不会因中断调度迁移到另一
CPU。偷取其他 CPU 页时再获取目标链表的锁。

### buffer cache 为什么不能简单按桶加锁？

缓存未命中会把 buffer 从一个桶迁移到另一个桶，涉及两把锁。若获取顺序不一致会
死锁；若查找与迁移不同步，会为同一 `(dev, blockno)` 创建重复缓存项。

### mmap 为什么使用缺页装入？

这样未访问的映射不消耗物理页，也不产生文件读取；大文件只为实际访问部分付费。
代价是 fault、fork、munmap 和 exit 都必须理解 VMA 生命周期。

### 网卡描述符的 DD 位表示什么？

它表示硬件已经完成对该描述符的处理。发送端只有看到 DD 才能回收旧 mbuf；接收端
只有看到 DD 才能把数据交给网络栈。
